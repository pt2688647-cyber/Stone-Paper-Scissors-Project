## 🎮 Stone, Paper, Scissor Game (Python)

Yeh ek simple command-line based game hai jo Python me likha gaya hai. Is game me user aur computer (robot) ke beech **Stone, Paper, Scissor** ka match hota hai.

### 🚀 Features

* User se input liya jata hai (Stone = 1, Paper = 2, Scissor = 3)
* Computer random choice generate karta hai (`random` module ka use karke)
* Har round ke baad result show hota hai:

  * Player wins
  * Robot wins
  * Draw
* Invalid input handle kiya gaya hai
* User `0` enter karke game exit kar sakta hai
* Game loop continuously chalta hai jab tak user exit na kare

### 🧠 Working Logic

* Player aur robot ke choices compare kiye jate hain
* Conditions ke basis par winner decide hota hai:

  * Stone beats Scissor
  * Paper beats Stone
  * Scissor beats Paper

### 🛠️ Technologies Used

* Python
* `random` module

### ▶️ How to Run

1. Python install hona chahiye system me
2. File run karo:

   ```bash
   python filename.py
   ```
3. Choice enter karo:

   * 1 → Stone
   * 2 → Paper
   * 3 → Scissor
   * 0 → Exit
